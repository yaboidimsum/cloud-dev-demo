### Priority Issues

*   **[P0] Severe Code Bloat in `animated-beam-landing-client.tsx`**  
    - **Why it matters:** The file contains over 500 lines of unused inline SVG paths (Zapier, Notion, Whatsapp, Messenger), adding dead weight to the bundle.
    - **Fix:** Strip unused inline SVGs and reference icons cleanly.
    - **Suggested command:** `/impeccable distill`

*   **[P1] Home Page Cognitive Overload & Miller's Law Violation**  
    - **Why it matters:** Expanding 14 work experience items with long copy blocks creates scanning fatigue for recruiters.
    - **Fix:** Truncate experience details, highlight only key bullet points, or structure the list step-by-step.
    - **Suggested command:** `/impeccable layout`

*   **[P2] Structural File Naming Mismatch (`sidebar.tsx`)**  
    - **Why it matters:** The component is named `sidebar.tsx` but renders as a bottom floating nav bar, which is misleading during code reviews.
    - **Fix:** Rename file and component to `bottom-nav-dock.tsx`.
    - **Suggested command:** `/impeccable polish`

*   **[P2] Disconnected Theme Control**  
    - **Why it matters:** The `ThemeSwitcher` floats in the bottom-right corner, separating layout adjustments from main navigation controls.
    - **Fix:** Integrate the theme toggles directly into the bottom navigation bar.
    - **Suggested command:** `/impeccable layout`

*   **[P3] Joking Work Experience Entry**  
    - **Why it matters:** The Twenty One Pilots band lore joke job ("Glorious Gone" in "Dema, Trench Continent") placed in formal work history can confuse recruiters scanning your profile.
    - **Fix:** Move this entry to a dedicated "Easter Egg" segment or remove it from the formal history list.
    - **Suggested command:** `/impeccable clarify`
